# FocusFlow

An original TypeScript task tracker built for the TypeTasks UI and shipping assignment.

## Run locally

1. Compile the typed source:

   ```bash
   tsc
   ```

2. Serve the folder with any static server, then open `index.html` in a browser.

The browser loads the generated `app.js`, which imports `model.js`.

## Assignment checklist

- HTML interface with task input, status selector, add button, task list, and filters.
- Typed DOM access in `app.ts` with no `any`.
- Add, advance, delete, and status filtering powered by `model.ts`.
- Compiled `app.js` and `model.js` included for static hosting.
- Original name, layout, colors, and visual treatment.

## Shipping

Push this folder to the same public repository used for Part 1, enable GitHub Pages (or use Netlify/Vercel), and include the repository URL and live URL in the pull request description.
